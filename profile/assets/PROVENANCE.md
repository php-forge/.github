# PHP Forge cover provenance

Prepared on 2026-11-03. `php-forge-cover-light.png` and `php-forge-cover-dark.png` are opaque PNG profile covers, each 1280 × 360 pixels. They contain the PHP Forge name and an artisan hammer resting on an anvil. The light and dark versions use the same composition with different backgrounds and text colors; neither has an orange rule.

## Artwork and typography

The hammer and anvil are generated supporting artwork, not an official emblem or a photograph of a real workshop. The selected Mjölnir-inspired scene was generated with the built-in image-generation tool. A subsequent image-model edit isolated the hammer and anvil on transparency and completed the cropped anvil. The edit is not an exact pixel cutout; details may differ from the initial scene. The transparent edited artwork used in the covers has SHA-256 `e43e16b0b1deb51ee97bb93855a17364a49ddb21398fda7c904a9c5d7380c086`.

The organization name was added separately in Nimbus Sans Bold. No font binary is included in these assets. The artwork does not establish an affiliation with any fictional franchise or the creator of a particular depiction of Mjölnir.
