# Pull Request

- [ ] Breaking change (fix or feature that would cause existing functionality to change)
- [ ] Bugfix (non-breaking change that fixes an issue)
- [ ] CI/build configuration
- [ ] Dependency update
- [ ] Documentation update
- [ ] New feature (non-breaking change that adds functionality)
- [ ] Performance improvement
- [ ] Refactoring (no functional changes)
- [ ] Tests

## Change

Explain the problem and the resulting behavior. Include a before/after example when useful.

## Validation

List the checks performed and their results. Explain any relevant checks not run.

## Compatibility

Describe any behavior, configuration, dependency, or migration impact. Write "None" when there is no compatibility
impact.

## Related issues

Link relevant issues. Use closing keywords only when this PR fully resolves them.
